3. One-Click GitHub Action & Terminal Integration

GitHub Actions Workflow

Drop into .github/workflows/brand-check.yml to post an automatic clearance table to your Job Summary and optionally gate builds on USPTO conflicts:

- name: Screen Product Name
  id: brand
  uses: zColdWater/brandshield-cli@v1
  with:
    name: "Lumora"
    tlds: "com,io,ai,co,app,dev"
    min-score: "70"
    fail-on-trademark: "true"
    post-summary: "true"

Zero-Install CLI (curl /cli.sh or Node 18+)

Screen any candidate from your terminal with zero packages installed:

# Instant POSIX shell audit (zero Node or npm required)
curl -fsSL https://brand-checker.appwrite.network/cli.sh | sh -s -- Lumora

# Or via Node 18+ GitHub CLI with Markdown CI threshold gate

  --markdown --min-score 75 --fail-on-trademark
